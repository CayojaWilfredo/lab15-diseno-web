# Laboratorio 15 - Diseño Web I

Autor: Wilfredo Jose Cayoja Medina. UPDS, 2026.

Sitio estático académico con HTML5, CSS y una portada alternativa de Bootstrap.
La plantilla incluida corresponde a Senderos Samaipata.

## Abrir localmente
Abrir index.html con Live Server en VS Code. La alternativa de Bootstrap está en version-bootstrap/index.html.
Las carpetas img y video deben copiarse desde la versión local del proyecto, conservando los nombres.

## Publicación
En Settings > Pages elegir GitHub Actions. El flujo Publicar sitio prepara y despliega el sitio automáticamente.
El enlace final aparece en Settings > Pages y en la ejecución del flujo.
La URL de canonical, los metadatos de página, el sitemap y la base de 404 se generan al publicar.

## Formulario
Es una demostración: navegar a gracias.html no envía una reserva real a una oficina.

## Actualizaciones
Modificar archivos del sitio, subir los cambios y guardarlos con un mensaje descriptivo.
El flujo vuelve a publicar la versión actualizada.
